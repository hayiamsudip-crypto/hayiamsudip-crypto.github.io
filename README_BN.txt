SUDIP MAHATA — ADVANCED PORTFOLIO (বাংলা নির্দেশিকা)

এই ZIP-এ আছে:
- index.html: ওয়েবসাইটের মূল পৃষ্ঠা
- style.css: ডিজাইন, মোবাইল-ফ্রেন্ডলি লেআউট
- favicon.svg: সাইট আইকন
- robots.txt ও sitemap.xml: সার্চ ইঞ্জিনের জন্য
- assets/profile.png: প্রোফাইল ছবি (যদি ZIP-এ থাকে)

GitHub Pages-এ প্রকাশ:
1) https://github.com/new খুলুন।
2) Repository name দিন: hayiamsudip-crypto.github.io
3) Public বেছে Create repository করুন।
4) Add file > Upload files দিয়ে ZIP Extract করা ফাইলগুলো আপলোড করুন।
   ZIP ফাইলটি নিজে আপলোড করবেন না; ভেতরের ফাইলগুলো আপলোড করবেন।
5) Commit changes করুন।
6) Settings > Pages > Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
   Save চাপুন।
7) কিছুক্ষণ পর ওয়েবসাইট খুলুন: https://hayiamsudip-crypto.github.io/

Google SEO:
1) ওয়েবসাইট প্রকাশের পর https://search.google.com/search-console/ খুলুন।
2) URL-prefix property হিসেবে https://hayiamsudip-crypto.github.io/ যোগ করুন।
3) যাচাইকরণ সম্পন্ন করুন (GitHub Pages-এর জন্য URL-prefix verification পদ্ধতি অনুসরণ করুন)।
4) Sitemaps-এ sitemap.xml জমা দিন।
5) Google-এ index হওয়া এবং সার্চে অবস্থান পেতে সময় লাগে; নিশ্চয়তা নেই।
